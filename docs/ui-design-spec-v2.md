## 1. 品牌与设计原则

### 1.1 定位

黄金珠宝 B2B2C 平台「平台自营」消费者端移动 H5，用于业务评审与研发交接。视觉目标是**可信、克制、以商品为主角**：不靠装饰取胜，靠商品图、价格与规格的可读性建立信任。

### 1.2 四条设计原则

`［官方］` 京东零售设计语言的四条原则，及其在本项目的落点：

| 原则 | 本项目落点 |
|---|---|
| 聚焦实效 | 首屏 3 秒内回答「是什么平台、金价多少、能买什么、下一步点哪」 |
| 简洁统一 | 全站纯白底、单一圆角族、六档字号；同类信息只出现一次 |
| 多元包容 | 正文 ≥14px、对比度 ≥4.5:1、点击区 ≥44×44，兼容小屏与适老化 |
| 品牌表现 | 品牌红只承担行动与交易，金色只承担品质与信任 |

### 1.3 视觉基调

1. **白底**：页面、卡片、弹层内容区、Tab 栏统一纯白 `#FFFFFF`，靠 1px 描边 + 最轻阴影分层。
2. **红即行动**：品牌红 `#E1251B` 只用于主 CTA、促销底、选中态；价格文字用更深的 `red-700`。
3. **金即品质**：金色用于会员、金价、证书、工艺，面积 ≤20%，不作背景、不作按钮。
4. **商品为主角**：商品图干净、1:1、无角标叠加；卡内只留售价，价格构成进商详。

## 2. 字体与字号

### 2.1 字体族

| Token | 字体栈 | 用途 |
|---|---|---|
| `--font-sans` | 系统字体优先（`-apple-system` / `PingFang SC` / `Noto Sans SC` / `Microsoft YaHei`） | 全站正文、标题、控件 |
| `--font-numeric` | 与 sans 同族的等宽数字特性 | 价格、金价、克重、订单号、计数 |
| `--font-serif` | `Noto Serif SC` / `Songti SC` / Georgia | 仅品牌字与氛围文案，**不用于价格与正文** |

- 不远程 `@import` 字体，不引入字体文件；中英混排时西文与数字跟随 `--font-numeric` 的等高数字。
- 数字场景统一 `font-numeric` + `.tabular`，保证纵向对齐。

### 2.2 语义字号角色

`［项目］` 全站只允许下列 9 个 role，组件与页面直接引用 role class（`text-display` / `text-title` …），禁止直接写 `text-[Npx]`。

| Role | 字号 / 行高 / 字重 | 典型用途 |
|---|---|---|
| `text-display` | 36 / 54 / 600 | 首页金价、结果页主数字 |
| `text-title` | 28 / 42 / 600 | 商详商品名、商详总价、页面主数字 |
| `text-section` | 21 / 32 / 600 | 区块标题、券面额、网格卡售价 |
| `text-card-title` | 16 / 24 / 600 | 卡片标题、二级页标题、订单状态标题 |
| `text-body` | 14 / 21 / 400 | 正文、说明、列表卡商品名（常规态） |
| `text-body-strong` | 14 / 21 / 500 | 强调正文、分类左栏条目、带字重按钮 |
| `text-label` | 14 / 20 / 500 | 按钮小字、筛选、Tab 文案、表单标签 |
| `text-caption` | 12 / 18 / 400 | 时间戳、单号、脚注、价格小数、Tab 文案 |
| `text-caption-strong` | 12 / 18 / 500 | 计数角标、图库计数器 |

### 2.3 字号档位

`［官方］` 字号阶梯为 14 / 21 / 24 / 28 / 36，正文不宜小于 14；`［项目］` 取 **36 / 28 / 21 / 16 / 14 / 12** 六档（16 为 14→21 之间的补充档，24 并入 21/28 以避免档位过密）。

| 场景 | 档位 |
|---|---|
| 首页金价、结果页主数字 | 36 |
| 商详商品名与总价、页面主数字 | 28 |
| 区块标题、券面额、网格卡售价 | 21 |
| 卡片标题、页面标题、列表卡售价 | 16 |
| 正文、商品名、规格、按钮、状态、表单 | 14 |
| 时间戳、单号、脚注、价格小数、Tab 文案、角标 | 12 |

### 2.4 数字与价格

- 价格、金价、克重、工费、订单号、计数：`font-numeric` + `.tabular`。
- 商品售价：`red-700 #A31610`，**必须落在白卡或浅色卡上**；禁止在米白/浅金 canvas 上直接放红字价格。
- 订单金额、结算应付、发票金额：`ink-900`，财务信息不用红。
- 金额保留 2 位小数；克重 2 位；网格卡售价取整到元以避让加购按钮。
- 划线原价：`ink-400` + 删除线；折扣、优惠、券：`red-600` 或 `red-50` 底 + `red-600` 字。

### 2.5 硬规则

- 字号只落在六档；**一屏不超过 4 级**，相邻层级差 ≥2px（推荐 ≥3px）。
- 层级靠字重与颜色差拉开，不靠加档；禁止新增第 7 档（18/20/24/32）。
- 正文、商品名、规格、按钮、状态 ≥14；12 仅限时间戳、单号、脚注、价格小数、Tab 文案、角标。
- 长文说明（FAQ 答案、`InlineNotice` 正文、吸底栏 note）用 14/21，不用 12。
- 行高符合字号 1.5–2.0 倍；不使用两端对齐；表格数字右对齐。
- 禁止裸字号 `text-[Npx]`、裸 `font-medium/font-semibold/font-bold`、任意 `leading-[..]`/`tracking-[..]`。
- 卡片内标题最高 16；唯一例外是网格卡售价可用 21（价格优先，不属于标题）。

## 3. 色彩

### 3.1 用色原则与取值说明

`［官方］` 色彩体系由核心品牌色、辅助色、渐变色、中立色构成，三条原则：

- **品牌性**：品牌、业务、主要功能控件使用品牌色；
- **识别性**：足够对比度、清晰易读、互不干扰；
- **包容度**：兼顾浅色与深色场景。

`［官方］` 品牌色为京东红 **Pantone 485C**，用于 LOGO、行动点、利益点、模块时保持原色，不减暗不调亮；辅助色由品牌红延伸；渐变避免撞色；**中立色在界面中占主导**。

**取值说明**：官方以色板图片呈现，未给 hex。本项目主色取 `#E1251B`（rgb 225/37/27），为长期通行的京东主红；Pantone 485C 的数码近似为 `#DA291C`，两者有可见差异。`red-50…900` 梯度与 `gold-*` 全系为本项目按主色与品类推导，非官方色板。

`［项目］` 用色比例：红 ≤10%/屏、金 ≤20%/屏；一屏 1 个红色实心主 CTA。

### 3.5 冲突规避（硬规则）

1. **红 ≠ 错误**：品牌红只表达行动、交易、优惠；错误一律 `danger-600` 且必须带图标与文案。
2. **红 ≠ 状态**：待支付用橙、待履约用绿、待收货用信息蓝、售后中用紫；状态标签不使用品牌红。
3. **红 vs 金**：同一卡片内不同时出现红底块与金底块；相邻时相隔 ≥8px，且一方降为文字级；金色绝不用于主按钮。
4. **红 vs 深色**：深色卡内不出现红色文字或按钮，CTA 用 `gold-300` 字或白底 `ink-900` 字。
5. **红面积**：单屏红色（含 CTA、价格、促销标签）≤10%，红色实心块 ≤2 个。
6. **金色面积**：单屏 ≤20%，只作文字 / 1px 线条 / 图标级强调，不作卡片或页面背景、不作按钮。
7. **渐变**：禁止页面级金色或浅金渐变；仅会员黑金卡等深色模块可用深金渐变，且不得铺满全页。

### 3.6 白底分层

- 页面、卡片、弹层内容区、Tab 栏统一 `#FFFFFF`；禁止任何浅金/米黄页面底色与页面级金色渐变。
- 白底白卡之间必须有 **1px `line` 描边 + 最轻一级阴影**（`shadow-xs`）；禁止仅靠底色差异分层、禁止无描边白卡。
- 深色区块（会员黑金卡、个人中心头部）保持深色块 + 圆角 + 边界，不与白卡混排在同一描边层，避免漂浮。
- 金色收敛为文字 / 1px 线条 / 20px 级图标。

## 4. 间距与栅格

### 4.1 间距刻度

**基准**：4px 网格；**只允许 6 档**：`4 / 8 / 12 / 16 / 24 / 32`。20 / 40 / 48 不使用；10（`*-2.5`）与 14（`*-3.5`）禁止。

| 场景 | 值 | 说明 |
|---|---|---|
| 页面左右安全边距 | **16** | 全站统一 |
| 页面顶部（导航栏下） | 12 | 与卡片间距一致 |
| 卡片内边距 | **16**（紧凑卡 12） | 商详/订单/购物车 16；商品卡 12 |
| 卡片间距 | **12** | 纵向列表；大区块之间 24 |
| 区块标题 → 内容 | 12 | |
| 元素行间距 | 8 | 文本行、图标与文字 |
| 按钮内边距 | 大 20/12；中 16/12；小 12/8 | 高度由 `min-h` 控制，不靠 padding 撑 |
| 底部 Tab 高度 | 52 + 安全区 | |
| 吸底操作栏 | 56 + 安全区 | |

### 4.2 栅格

- 内容区：375 − 16×2 = **343**。
- 两列商品卡：`(343 − 12) / 2 ≈ 165.5`，取 165/166。
- 三列分类宫格：`(343 − 12×2) / 3 ≈ 106`。
- 四列入口：`(343 − 8×3) / 4 ≈ 79.75`，图标 40 居中。
- 分类页左栏 **76**，右栏 `343 − 76 − 8 = 259`，网格 2 列卡宽 **126**，列表项图 88×88。

**禁止**：卡片内再套卡片；同一屏出现 3 种以上外边距。

## 5. 圆角与阴影

`［官方］` 圆角用于视觉聚焦与层级感知，按元素大小选曲率，一个页面控制在 2–3 种；阴影默认光源为垂直向下平行光，Z 轴越高越弥散，无色相模块用纯黑调透明度并多层叠加。

| Token | 值 | 用途 |
|---|---|---|
| `radius-xs` | **4** | 徽章、角标、状态标签 |
| `radius-sm` | **8** | 输入框、缩略图、小控件、图片容器 |
| `radius-md` | **12** | 按钮、列表项、紧凑卡片、吸底栏 |
| `radius-lg` | **16** | 标准卡片、底部弹层、主视觉卡片 |
| `radius-pill` | 999 | **仅**筛选 chip、头像、开关、计数圆点、圆形图标按钮、进度条、搜索框 |

| Token | 值（多层、纯黑） | 用途 |
|---|---|---|
| `shadow-0` | none + 1px `line` | 页面内普通卡片（默认） |
| `shadow-xs` | `0 1px 2px rgb(0 0 0/.04), 0 1px 1px rgb(0 0 0/.03)` | 可点卡片静置 |
| `shadow-sm` | `0 2px 6px rgb(0 0 0/.05), 0 1px 2px rgb(0 0 0/.04)` | 悬浮/选中卡片、吸顶栏 |
| `shadow-md` | `0 6px 16px rgb(0 0 0/.07), 0 2px 6px rgb(0 0 0/.05)` | 吸底操作栏、浮层 |
| `shadow-lg` | `0 12px 32px rgb(0 0 0/.10), 0 4px 12px rgb(0 0 0/.06)` | 底部弹层 |

**规则**

- 同屏阴影不超过 2 级；卡片默认用描边而非阴影。
- 圆角与尺寸匹配：小元素小圆角、大卡片 16；**卡片与按钮不得用胶囊**。
- 禁止彩色阴影与 warm-ink 着色阴影；金色主视觉卡允许内发光/渐变，但不得再加外阴影。
- 同一屏圆角种类 ≤3。

## 6. 图标与图片

### 6.1 图标

`［官方］` 图标三原则：**准确**（表意不困扰）、**高效**（简洁少修饰）、**亲和**（圆角呼应轮廓）。线性用于 Tab 未选中、导航栏、二级功能入口；面性用于 Tab 选中、一级页导流入口。

- 图标来源统一 `lucide-react`，同一区域同一状态不混用线性与面性。
- 尺寸：`16`（行内）/ `20`（默认）/ `24`（导航、Tab）。
- 线宽统一默认值，不单独调整 stroke。
- 颜色：默认 `ink-700`；选中/强调 `gold-700`；不使用多色图标。
- 品类图标必须可辨识：手镯→开口镯、项链→链坠、戒指→指环、耳饰→耳钩、手链→链节、吊坠→坠形、金条→条块、金章→圆章、金豆→豆粒。**禁止用圆、虚线圈、圆点区分品类**。
- 图标必须有 `aria-label` 或可见文字；纯图标按钮点击区 ≥44×44。
- 以视觉中心而非数值中心对齐，同组图标灰度复杂度一致。

### 6.2 商品图展示

`［官方］` 图像三原则：**清晰**、**真实**、**自然**。

- **统一 1:1**：卡片、列表、购物车、订单缩略图、商详图库全部 1:1；图片与容器同比例，`object-cover` 不裁切主体。
- 主体占比：展示端 55%–80%（主体更满利于识别与点击）；送审白底图另出约 60% 版本，不用 CSS 缩放改造。
- 图片容器底色统一米白拍摄底；容器圆角：卡片图 8、商详图库 16（外层卡片）、缩略图 8。
- **商品图上零叠加**：不得叠加「可自提 / 按克 / 新品 / 售罄」等任何角标、半透明底或占位；状态只进卡内文字或商详规格区。
- 系列/活动图：横幅 2:1 或 16:9；专题卡 4:3。
- 无图时用统一「浅底 + 品类线性图标 + 商品名首字」占位，**不得用渐变几何图形伪装商品**。
- 页面只读 `product.images` 映射，**禁止硬编码图片路径**。

### 6.3 商品图生产

每个 SKU 固定三张同底素材，对应商详图库三帧。

**（1）三类图定义**

| 类型 | 数据字段 | 内容 | 使用位置 |
|---|---|---|---|
| 主图 | `images.main` | 商品正面、无道具、居中 | 列表卡、商详第 1 帧 |
| 工艺图 | `images.craft` | 材质与工艺微距：錾刻/锤揲纹理、拉丝、爪镶爪口、链扣、刻字 | 商详第 2 帧，回答「做工如何」 |
| 佩戴 / 细节图 | `images.wear` | 手镯/手链/手串→腕部；项链/吊坠/锁骨链→颈部；戒指→手部；耳饰→耳部；金条/金豆/金章→手持或细节特写 | 商详第 3 帧，回答「戴上什么效果、多大体量」 |

- 工艺图必须对应该 SKU 的 `craft` 与商品名，不得套用其他工艺；数据缺工艺描述时按商品名/材质/器型推断，并列出推断清单。
- 佩戴图只允许局部身体（手、腕、颈、耳）；**禁止真人全身、禁止五官与完整侧脸**（下颌线以上露脸即不合格）。

**（2）规格与一致性**

| 项 | 取值 |
|---|---|
| 比例 / 尺寸 | 1:1 / **1600×1600** |
| 格式 | JPEG，sRGB，单张 60–260KB |
| 背景 | 统一米白拍摄底（边缘中位色差 ≤10/255） |
| 光线 | 单主光左上约 45°，色温 5200–5600K |
| 主体占比 | 55%–75%，三张接近 |

- 生成后统一 `sips -c 1600 1600` 居中裁切，再逐张核对。
- 不得改变商品比例与克重视觉：细链不得生成粗链、3 克不得生成 8 克体量、素圈不得生成宽面戒、单颗金豆不得生成大金块。

**（3）禁止元素**

- 人脸、全身模特、手部畸形/多指/断指；耳部图不得出现脸颊、下颌、额头。
- 品牌 LOGO、水印、可读文字、刻字乱码、价格贴片；营销角标一律由前端叠加。
- 非金材质误导（银白金属、镀层、塑料感）、过度 HDR 炫光、镜面倒影与道具。
- 夸张星芒、过度磨皮锐化、AI 伪影；与规格不符的工艺、克重、镶嵌数量、链长、圈口。

**（4）命名与映射**

```
public/assets/products/p{NN}.jpg          # 主图
public/assets/products/p{NN}-craft.jpg    # 工艺图
public/assets/products/p{NN}-wear.jpg     # 佩戴 / 细节图
```

- `p{NN}` 与 `src/data/products.ts` 中每个 SKU 的 `asset` 严格一致。
- `images.{main|craft|wear}` 为 `{ src, alt }`，alt 由数据层生成：主图「{商品名} 主图」、工艺图「{商品名} 工艺特写，{工艺}」、佩戴图「{商品名} 腕部/颈部/手部/耳部佩戴 / 手持细节」。

**（5）验收（逐 SKU、逐张）**

- [ ] 无乱码、无水印、无畸形结构、无五官；不合格重生成，不凑数。
- [ ] 三张同底、同色温、同光位，主体占比接近。
- [ ] 工艺与 `craft` 一致；佩戴部位与器型一致；视觉克重与标注克重相符。
- [ ] 尺寸统一 1600×1600，全部可访问、无 404。

## 7. 组件规范

所有组件支持 `className` 透传、`size`/`tone` 枚举；组件内部不写死业务文案。

### 7.1 按钮 Button

| 类型 | 样式 | 使用 |
|---|---|---|
| Primary | `red-500` 底 + 白字，`radius-md 12`（非胶囊） | 每屏 1 个主行动 |
| Secondary | 白底 + `red-500` 1px 描边 + `red-600` 字 | 加入购物车、查看详情 |
| Tertiary | 透明 + `ink-500` 字 | 取消、稍后 |
| Text | `red-600` 字 + 可选箭头 | 行内跳转 |
| Disabled | `canvas` 底 + `ink-400` 字 | 售罄、未选条件 |

- 高度：L 48 / M 44 / S 36（S 视觉高 36，点击区补足 44）。主操作 ≥44；辅助筛选/标签 ≥32 且间距 ≥8。
- 字号：L/M `text-body-strong` 14/500；S `text-label` 14/500。
- 深色卡内不得用红色按钮，改 `gold-300` 字或白底 `ink-900` 字。
- 按下态：品牌红不调暗，用 `inset 0 0 0 100px rgba(0,0,0,.08)` 遮罩；确需深红仅限小面积 `red-600`。
- 非品牌红按钮按下态用 `scale(0.98)` + 背景明度 −6%；禁用态无按下态。

### 7.2 输入框 Input

- 高度 44，`radius-sm 8`，底色 `paper`，边框 `line`；聚焦边框 `red-500` + 2px 8% 红外发光。
- 字号 14；占位符 `ink-400`；错误文案 12 `danger-600`，置于框下 4px。
- 手机号/身份证使用 `inputMode`；不得用 placeholder 代替 label。

### 7.3 标签 / 徽章 Badge

- 高度 20（sm）/ 24（md），字号 `text-caption` 12，`radius-xs 4`（非胶囊）。
- 底色为语义色 8%–10%，文字为语义色；不使用高饱和大色块。
- 促销/优惠：`red-50` 底 + `red-600` 字 + `red-200` 描边；会员/证书：`gold-100` 底 + `gold-700` 字；二者不同排。
- 一屏同类标签 ≤3 个；商品图上禁止叠加任何角标。

### 7.4 订单状态标签

- 高 22，字号 12/500，圆角 4，右侧对齐于订单头。
- 语义色固定（见 §3.2）；状态标签不换行，不把计数塞进标签文字。
- 订单列表筛选用横向滚动 Tab，不用状态标签堆叠。

### 7.5 分段控件 / 筛选 Chip

- 高度 32、字号 `text-body` 14/500、`radius-pill`、间距 8。
- 选中：`red-50` 底 + `red-700` 字 + `red-200` 描边；未选：`paper` + `line` 描边 + `ink-500` 字。
- 计数以「文字 + 4px + 数字」呈现，数字 `text-caption` 12 `tabular`，不放进圆形角标。
- 横向溢出时滚动不换行，左右各留 16px 渐隐遮罩。

### 7.6 底部操作栏 BottomActionBar

- 高 56 + `safe-area-inset-bottom`；白底 + 上边框 + `shadow-md`。
- 左侧价格/说明区，右侧 1 个主按钮，按钮宽 ≥120。
- 不与底部 Tab 同屏；有吸底栏时页面底部预留 `56 + 安全区 + 12`。

### 7.7 列表项

- 单行高 ≥56，双行 ≥72；左图标 20、右箭头 16。
- 标题 `text-card-title` 16，副标题 `text-body` 14/400 `ink-500`；分隔线 `line-soft`，缩进对齐文字起点。

### 7.8 商品卡 GoodsCard

- **统一数据**：网格与列表共用同一份 `Product`、筛选与排序状态；视图切换只改布局，不重置筛选。
- **网格卡（默认 2 列）**：图 1:1 → 名称 `text-card-title` 16，最多 2 行 → 属性一行（成色 · 克重）→ 售价 `text-section` 21 + 右下角加购。内边距 12、卡间距 12、`ring-1 ring-border-subtle` + `shadow-xs`。
- **列表卡（单列）**：左 120×120 图 → 右侧名称 16（最多 2 行）+ 属性一行 + 售价 16 + 右下角加购；整项最小高 144。紧凑态（分类页右栏）图 88×88、名称 14、价格取整。
- **只留售价**：卡内不出现工费、克价、总价构成，明细只在商详 `PriceBreakdown`。
- **图片零叠加**：商品图上不叠加任何 badge、半透明底或占位。
- **加购按钮**：视觉圆 28（`h-7 w-7`），可点区 44（`h-11 w-11` 透明区），白底 + 红描边 + 红「+」；点击后 1.2s 内变红底白勾（不使用 toast）；`aria-label="加入购物车：商品名"`；`stopPropagation` 防止跳商详。
- 名称不得单行 `truncate`；属性行可换行；价格行 `pr-9` 为加购留位。
- 同一列表内价格位置、字号、颜色一致；售罄项以文字「暂时售罄」替代价格。

### 7.9 商品列表排序 / 筛选行

- 单行、吸顶（`sticky top-0 z-20`），白底 + 下边框 + 轻模糊，高度 52。
- 左：综合 / 工费低 / 价格（点击循环升序 → 降序），选中品牌红，价格项带 12px 箭头，文字 `text-label` 14。
- 右：「筛选」文本入口（有选中项时红色 + 计数徽章）+ **单一**视图切换图标（44×44，图标形状即当前视图，网格 ↔ 列表）。
- 375 下不换行；筛选打开底部抽屉；视图切换不影响筛选条件。

### 7.10 空状态 EmptyState

- 图标 48（`ink-400`，非金色）、标题 `text-card-title` 16/600、说明 `text-body` 14/`ink-500`、1 个主按钮。
- 文案给下一步，不写「暂无数据」这类系统语。

### 7.11 加载态

- 列表骨架屏：卡片轮廓 + 3 条灰条（`line-soft` → `line` 1.2s 循环；加载循环不受 640ms 上限约束）；不用转圈遮罩整页。
- 图片加载：先显示同尺寸底色占位，加载完成后淡入 160ms。

### 7.12 弹窗 / 浮层

- 底部弹层上圆角 16、`shadow-lg`、遮罩 `rgba(0,0,0,.45)`。
- 仅用于「选择规格/门店/地址」等需要阻断的操作；确认类优先用页面内 `InlineNotice`。

**底部抽屉 / 筛选弹层**

- 结构：遮罩 + 底部上滑白色面板；面板 `max-height: 80%`，内容区独立滚动，头部与底部操作区固定。
- 头部：高 48，标题 16/600，右侧关闭按钮 44×44。
- 分组：组标题 `text-label` 14 `subtle-foreground`；选项 chip `min-h-8`（32）、`rounded-full`、`px-3`；选中 `bg-red-50 text-red-700 ring-red-200`，未选 `bg-card text-muted-foreground ring-border-subtle`。
- 底部操作区：`border-t` 固定；左「重置」次按钮 + 右「确定（N）」主按钮，高度 ≥44，宽度约 1 : 1.6。
- 安全区：底部操作区 `padding-bottom: calc(16px + env(safe-area-inset-bottom))`；内容滚到底完整露出。
- 动效：遮罩 `opacity` 240ms、面板 `translateY` 240ms（`--motion-base` / `--ease-enter|exit`）；`prefers-reduced-motion` 下取消位移。
- 关闭：点遮罩、关闭按钮、Esc、浏览器返回、头部下滑 >80px；打开时锁背景滚动，焦点进入面板。
- 确认制：抽屉内选中即时高亮，列表仅在点「确定」后更新。

### 7.13 Toast（禁止）

- 本项目不新增 toast。业务告知使用 `InlineNotice` 或行内文案。
- 如确需提示组件，需先确认文案、位置、时长并写入需求文档。

### 7.14 底部 Tab

- **固定 5 项等分**：首页 / 商品 / 分类 / 购物车 / 我的；375 下每项约 73 宽，文案不截断、不换行。
- 高约 52 + 安全区；图标 20、文案 `text-caption` 12/400，字号写在容器上常驻。
- **选中态只做两件事**：图标线性转面性（`fill=currentColor`）+ 文字变品牌红；字号、字重与未选中完全一致，禁止放大加粗。
- 角标：高 16、字号 `text-caption-strong` 12、`red-500` 底白字，右上偏移 6；99+ 截断；仅购物车挂角标。
- 点击区 ≥44×44。

### 7.15 演示左栏 PrototypeNav

- 定位：桌面评审辅助 UI，只服务页面跳转，**不属于产品界面规范**，不得进入正式页面或作为复用样式。
- 字号 `text-label` 14/500；3 列网格（`grid-cols-3 gap-2`），侧栏宽 300；单项 `min-h-9`（36）、`whitespace-nowrap`、居中。
- 选中态：品牌红文字 + 浅红底。

### 7.16 轮播 Carousel

- 画布：宽高比 **2:1**（375 下 343×172），`rounded-lg`、`shadow-sm`、`bg-surface`。
- 图片：右侧 1:1 图片窗口（高 72% 画布、`rounded-md`、`object-cover`）；首张 eager，其余 lazy。
- 文案：眉标 `text-label` 14（`gold-700`）、标题 `text-card-title` 16、操作「立即查看 ›」`text-label` 14；文案区最多两行。
- 交互：Pointer 拖拽阈值 40px；自动播放 4500ms，手动滑动、页面不可见、`prefers-reduced-motion` 时暂停或重置；末张循环首张。
- 指示点：数量与张数一致；点击区 24×24，当前 `h-2 w-2 bg-primary`，其余 `h-1.5 w-1.5 bg-ink-900/25`。
- 动效：`translateX` 320ms（`--motion-slow` / `--ease-standard`）。
- 无障碍：容器 `aria-roledescription="carousel"` + `aria-label`；非当前页 `aria-hidden` 且 `tabIndex=-1`；指示点带 `aria-label` 与 `aria-current`。

### 7.17 商详图库 ProductGallery

- 位置：商详首屏媒体区，卡片内满内容宽（375 下 **343**），1:1，高度 343。
- 结构：`main → craft → wear` 三张横排；原生滚动 + `scroll-snap-type: x mandatory`，每张 `w-full shrink-0 snap-center`；整张吸附，不出现半张、不留 gap；容器隐藏滚动条。
- 交互：触摸横滑（原生滚动）；鼠标按住拖拽（阈值 4px，拖拽期间临时关闭吸附，松开补间到最近页）；容器可聚焦，`← / →` 切换；**只做水平位移，不做缩放与淡入淡出**。
- 动效：位移补间 320ms（`--motion-slow`），缓动近似 `--ease-enter`；`prefers-reduced-motion` 下直接定位。
- 指示器：右下角计数器「1/3」，`text-caption-strong` + 半透明深底白字；不采用底部圆点。
- 加载：首图 eager，第 2/3 张 lazy；容器固定 `aspect-square`，防加载与切换时抖动。
- 无障碍：容器 `role="group"` + `aria-label="商品图片，左右滑动查看"`；每张独立 alt；键盘可切换。
- 回退：任一图加载失败回退主图（仅一次），不出现破图。
- 边界：图库内禁止叠加状态角标或促销贴片；商详价格算式、规格、证书、评价、同系列推荐不因图库变化。

## 8. 移动端布局与适配

### 8.1 基准与设备框

- **设计基准 375×812**，内容宽 `375 − 16×2 = 343`。
- 桌面预览框：内容宽固定 375，边框 9px，整机 393。
- 375 是设计基准而非最大宽度：真实设备更宽时容器与图片伸展，字号不变。
- `viewport` 为 `width=device-width, maximum-scale=1.0`；不使用 rem 缩放，采用 px + Tailwind + 弹性宽度。

### 8.2 宽度档位

## 9. 交互与动效

`［官方］` 四原则：自然流畅、引导有序、体验提效、品牌表现力；强调减速过程与临界阻尼，路径优先弧形；产品动效 160–640ms，营销动效 320–1000ms，超过 1s 显拖沓；等待超过 8s 需浮层提示。

| Token | 值 | 场景 |
|---|---|---|
| `motion-fast` | **160ms** | 按下/松开、hover、选中态、图片淡入 |
| `motion-base` | **240ms** | 卡片/按钮状态切换、Tab 切换、渐隐渐现 |
| `motion-slow` | **320ms** | 底部弹层、容器过渡、页面转场、图库位移 |
| `motion-max` | **640ms** | 产品动效总时长上限（含 stagger） |
| `motion-marketing` | **320–1000ms** | 营销氛围与首屏视效 |
| `ease-standard` | `cubic-bezier(0.2, 0, 0, 1)` | 默认减速 |
| `ease-enter` | `cubic-bezier(0.16, 1, 0.3, 1)` | 进入、弹层 |
| `ease-exit` | `cubic-bezier(0.4, 0, 1, 1)` | 退出、收起 |
| `ease-spring` | `cubic-bezier(0.34, 1.2, 0.64, 1)` | 仅小面积反馈，幅度 ≤4px |

- 按下态：`scale(0.98)` 或背景明度 −6%（品牌红不调暗，用遮罩），时长 160ms。
- 进入用 `ease-enter` + 位移 ≤8px 或透明度；退出用 `ease-exit`，可比进入快一档。
- 只对用户操作产生的结果做动效；禁止无限循环装饰动画。
- 页面切换不做整页位移；滚动吸顶用 `sticky`，不加滚动监听动画。
- 加载例外：骨架屏与进度循环不受 640ms 限制；超过 8s 的等待转浮层 + 文案。
- 尊重 `prefers-reduced-motion`：关闭位移与弹性，仅保留透明度，时长降至 0.01ms。

## 10. 文案与信息层级

**信息优先级（自上而下）**：品牌/品类 → 核心数字（金价/价格）→ 关键规格（成色/克重/工费）→ 信任（自营/证书/退换）→ 行动。

**文案规则**

- 标题写「是什么」，副标题写「有多少/什么状态」；不写空泛口号（如「按品类找货」）。
- 数字必须带单位：`元/克`、`克`、`件`、`元/件`；金额 2 位小数，克重 2 位。
- 同一概念全站统一：`工费`（不写加工费/手工费）、`锁价`、`自提`、`报价单`。
- 禁止用户可见的内部语言：`mock`、`demo`、`P0/P1`、`status=xxx`、URL 参数、组件名、代码常量。
- 禁止在正式页面出现「本期不规划 / 示例数据 / 演示工具」等说明，此类内容只允许出现在 `PrototypeNav`。
- 错误文案说「怎么解决」，不说「操作失败」；不出现成段规则说明与算式解释，规则通过组件行为体现。

**标题层级**

- 区块标题：`text-section` 21/600
- 卡片标题、页面标题：`text-card-title` 16/600
- 商品名、正文：`text-body` 14（网格卡商品名用 16）
- 辅助信息：`text-caption` 12/400，仅用于非决策信息
- 不设类目大标题；当前类目只由左栏选中态表达。

## 11. 无障碍与可点区域

- **最小点击区 44×44**（Apple HIG 44pt / Material 48dp / 微信 7–9mm）；辅助筛选、标签类 ≥32 且间距 ≥8。
- 对比度：正文 ≥4.5:1，大字（≥18.66px 粗体）≥3:1；`ink-400` 不承载信息。
- 状态不能只靠颜色：状态标签必须带文字；选中态可加描边或字重，**底部 Tab 例外**——只变色与图标形态。
- 图标按钮必须有 `aria-label`；开关用 `role="switch"` + `aria-checked`。
- 焦点可见（桌面预览）：`outline: 2px solid gold-600; outline-offset: 2px`。
- 表单错误与字段关联（`aria-describedby`），错误不只靠红色。
- 图片必须有 alt；装饰性图片 alt 为空。
