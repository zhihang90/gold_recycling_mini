行情与资讯 需求文档

版本 v1.0 日期 2026-11-23 来源 《投资金APP架构设计文档 v1.1》行情服务模块 载体 用户端 H5 原型

1 背景与目标

架构文档把行情列为 P1 核心能力：用户不仅要“看到实时金价”，还要在同一页面完成 判断 → 换算 → 下单，并在价格波动时收到提醒。当前原型的行情页只有价格概览与近 7 日柱状示意， 缺少标的切换、图表分析、关联产品、快捷交易、自选提醒与资讯承接，无法支撑“看价到下单不超过两步”的要求。

本版本把行情页升级为「行情 + 资讯」两个一级 Tab：行情 Tab 承载看价与决策，资讯 Tab 承载快讯与解读， 资讯条目可进入独立全屏详情页。自选与到价提醒先做本地演示态，验证交互与信息结构，不接真实推送。

可观察结果：用户进入行情页可在 1 次切换内看到目标标的的实时价、涨跌与关键数据；可从行情页直接用预设克重测算金额并进入下单； 可在资讯 Tab 浏览快讯并打开详情阅读全文；可为标的加自选、设置到价提醒并在页面内收到提醒反馈。

2 范围与优先级

优先级范围说明
P0 双 Tab 容器、行情概览、图表骨架、关联产品、报价与快捷交易、自选、到价提醒（本地）、合规风险、资讯流、资讯详情、稳定性状态 首版必须形成完整闭环：看价 → 换算/下单 → 看资讯 → 设提醒
P1 元/盎司与人民币/美元计价切换、历史事件标注、每日/每周金价小结、资讯下拉刷新与分页加载 在 P0 稳定后补齐，不阻塞首版评审
不做 真实 WebSocket 推送、系统级推送通知、资讯标签筛选、资讯独立列表页、评论/点赞/分享落地页 与“本地演示态”和“资讯无独立列表页、不做标签”的决策一致

说明：架构文档中的 P2（定投、会员权益等）不在本文档范围内。

3 产品模型

3.1 核心对象

对象定义关键字段
行情标的（Quote） 可被展示与交易的报价对象 标的编码、名称、分组（平台/上金所/国际）、计价单位、现价、涨跌额、涨跌幅、今开/最高/最低/昨收、成交量、成交额、数据来源、报价时间、交易状态
关联产品（Related） 影响金价判断的周边品种与汇率 名称、编码、价格、涨跌幅、单位
资讯（News） 快讯与解读内容 标题、发布时间、来源、正文段落、缩略图、是否含外链
自选（Watch） 用户置顶关注的标的 标的编码、加入时间、排序
到价提醒（Alert） 用户对某标的设置的目标价提醒 标的编码、方向（高于/低于）、目标价、创建时间、状态（待触发/已触发/已失效）

4 信息架构与路由

行情为底部一级 Tab（第三位），页内采用两个一级 Tab 切换行情与资讯。资讯详情为独立全屏页面，直接访问也可用。

页面路由层级返回目标
行情 / 资讯（双 Tab 容器）/market（?tab=quote 默认 / ?tab=news）一级 Tab—
资讯详情/market/news/:newsId二级全屏返回 /market?tab=news
URL 直接带 ?tab=news 时，必须直接落在资讯 Tab，不出现先渲染行情再切换的闪动（首帧即按查询串初始化）。 资讯详情刷新/直达时按 newsId 读取内容，找不到时展示空态并提供“返回资讯”按钮。

页面层级

底部 Tab：行情→ 页内 Tab：行情 / 资讯→ 资讯条目→ 资讯详情（独立路由）→ 返回资讯 Tab

5 功能需求

FR-01

行情 / 资讯 双 Tab 容器

P0
目的
让“看价”和“看资讯”在同一入口内完成，减少跳转层级。
布局
页面顶部为等宽两个 Tab：行情、资讯，带下划线指示条；Tab 下方为各自内容区；底部保留全局 Tab 栏。
触发
进入 /market 或点击页内 Tab。

处理规则

  • 默认选中“行情”；点击 Tab 时以 replace 写入 ?tab=，不污染历史栈。
  • 切换 Tab 只替换内容区，不整页刷新；行情价格状态在切走再切回后保持（本地数据不重置）。
  • 页内 Tab 吸顶，滚动长列表时仍可切换。
  • 资讯 Tab 打开详情后返回，需回到资讯 Tab 且保持列表滚动位置。

状态与异常

场景表现
非法 tab 参数回落为行情 Tab
从详情返回按返回目标进入资讯 Tab，列表滚动位置还原

处理规则

  • 标的切换为横向可滚动胶囊组，选中态用金色描边高亮；切换后大号价格、关键数据、图表、报价入口同步切换。
  • 涨跌额 = 现价 − 昨收；涨跌幅 = 涨跌额 ÷ 昨收 × 100%，保留 2 位小数；涨红、跌绿、平盘用中性色。
  • 每次刷新时数字做 300ms 内的高亮闪动，避免高频动画。
  • 报价时间与数据来源必须与价格同时可见；时间精确到秒。
  • 单位切换（元/克 ↔ 元/盎司）为 P1，顶部以“元/克”文字按钮提示可切换。

场景表现

休市价格置灰，概览区顶部出现“休市中”说明条，快捷交易不可用

FR-03

图表分析区

P0十字光标 / 指标为 P0 骨架
目的
让用户判断短期走势，而不只是看一个价格点。
布局
分时 / K 线切换 + 周期选择（1分、5分、15分、1小时、日、周、月）+ 指标开关（MA5/10/20、成交量、MACD）。

处理规则

  • 默认：分时图，周期“日”；分时图不显示 MA，K 线默认显示 MA5/MA10。
  • 切换标的、周期时重新加载该组合的走势；加载中在图表区内展示骨架，不整页刷新。
  • 拖动十字光标显示该时点价格、涨跌与时间；松手 2 秒后自动隐藏。
  • 图表区域高度固定，避免切换周期造成页面跳动；横屏不另做布局。
  • 历史大事件、节假日休市标注：以竖线 + 文字标签呈现，首版只保留“休市”标注（历史事件为 P1）。

状态与异常

场景表现
该周期无数据图表区空态“暂无该周期数据”，其余区块正常
休市图表可看历史，最新点后追加“休市”标签

FR-05

报价与快捷交易入口区

P0
目的
把“看到价格”直接连接到“算出金额并下单”，满足看价到下单不超过两步。
布局
买入价 / 回购价并排 → 价差与手续费说明 → 规格选择（5g/10g/20g/50g/100g）→ 实时金额 → 主按钮「立即买入」+ 次按钮「预约购金」「申请回购」→ 锁价说明。

计算规则

项规则
买入金额规格克重 × 平台买入价 + 手续费；手续费费率 TBD
回购金额规格克重 × 平台回购价 − 折价/损耗；折价规则 TBD（回购为 P1 文案入口，不进入真实流程）
价差展示买入价与回购价差额，明码标注“买卖价差 ¥x.xx/克”
金额精度保留 2 位小数，四舍五入；展示千分位

交互规则

  • 切换规格时金额即时重算，带 150ms 数字过渡；默认选中 10g。
  • 「立即买入」带当前标的与规格进入确认订单页；「预约购金」进入预约购金流程入口；「申请回购」在回购未上线前置灰并提示“即将开放”。
  • 锁价说明固定展示：“下单后成交价以订单确认时的系统报价为准，锁价时效 60 秒，超时自动取消并重新报价”。
  • 休市、数据延迟超过阈值时，「立即买入」置灰并说明原因。

状态与异常

场景表现
报价跳变确认订单页校验价格区间（2~5 元可配置），超出时提示重新确认价格
锁价超时沿用现有订单倒计时与自动取消逻辑
休市按钮置灰 + “当前休市，开市后可交易”
FR-06

自选（本地演示态）

P0
目的
让用户把常看的标的固定在顶部，减少每次切换成本。
入口
概览区标的胶囊右侧星标；自选区“管理”。

处理规则

  • 点星标切换收藏；收藏后标的进入“自选”分组并排在最前，取消后移回原分组。
  • 自选数据保存在浏览器本地（gold_market_watchlist），刷新、重开页面保持；清空需在“管理”中逐个移除或全部清空。
  • 自选数量上限 8 个，达到上限再收藏时提示“自选最多 8 个，请先移除”。
  • 无自选时自选区不展示，仅保留星标入口，避免空区块占位。
FR-07

到价提醒（本地演示态）

P0
目的
用户不必盯盘，价格到达心理价位时得到反馈。
入口
概览区“设提醒”文字按钮；自选标的长按/更多菜单（二选一，原型用前者）。
形式
底部弹层：当前标的 + 当前价 + 方向（高于/低于）+ 目标价输入 + 确认。

处理规则

  • 目标价必填，正数，最多 2 位小数；与当前价比较后自动建议方向（高于现价默认“高于”，低于默认“低于”）。
  • 同一标的最多同时存在 3 条待触发提醒；重复目标价给出提示。
  • 保存后进入“我的提醒”列表（行情页底部入口），展示标的、方向、目标价、状态与创建时间。
  • 演示态触发：页面内用定时器模拟报价波动，命中目标价后展示页面内提醒条 + 提醒状态改为“已触发”，不调用系统推送。
  • 提醒可删除；已触发提醒保留 7 天展示（演示态按本地时间计算）。

FR-08

合规与风险提示

P0

处理规则

  • 本机首次进入行情 Tab，弹出风险提示弹窗：说明黄金价格波动、盈亏自担、资讯不构成投资建议；用户勾选“我已阅读并理解”后才能点击“继续查看”。
  • 弹窗不可点遮罩关闭；未确认前行情数据区置灰，不展示可交易按钮。
  • 确认后记录本地标记（gold_market_risk_ack），后续进入不再弹出。
  • 行情页底部常驻风险声明：“黄金价格波动，盈亏由用户自行承担”。
  • 休市、暂停交易时报价置灰并说明原因，禁止进入下单。

FR-11

交互稳定性与异常兜底

P0
  • 行情数据每 5 秒模拟刷新一次；页面隐藏（切后台）时暂停刷新，回到前台立即刷新一次并更新报价时间。
  • 模拟断线：连续 30 秒无刷新视为断线，顶部出现重连提示条；恢复后提示“已恢复实时行情”，价格继续刷新。
  • 所有价格区块在刷新失败时保留上一次数据，并标记“数据延迟”，不清空成 0。
  • 异常报价（价格 ≤ 0、涨跌幅绝对值超过 20%）不展示为可交易价格，显示“报价异常，请稍后重试”。
  • 资讯与行情各自加载互不阻塞：资讯加载失败不影响行情展示，反之亦然。
FR-12

6 共享规则

6.1 红涨绿跌

涨为红色、跌为绿色、平盘为中性灰；行情、关联产品、资讯内嵌行情数字统一遵循，不允许局部反色。

6.2 价格精度与单位

类型精度单位

汇率4 位小数人民币/外币
金额合计2 位小数，千分位元

6.3 单位换算（P1）

元/克 ↔ 元/盎司：1 盎司 = 31.1035 克；默认按克展示，切换后保留换算结果 2 位小数，并标注“按 31.1035g/oz 换算”。

6.5 合规文案

  • 风险弹窗：黄金价格受国际形势影响波动较大，投资有风险，盈亏由用户自行承担。
  • 页面常驻：黄金价格波动，盈亏由用户自行承担。
  • 资讯声明：资讯仅作信息参考，不构成投资建议，不承诺收益。
  • 交易入口：下单后成交价以订单确认时的系统报价为准，锁价时效 60 秒。
